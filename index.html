Overview

This project is a 1 kW two-stage Solid-State Transformer (SST) prototype. The system consists of a boost PFC rectifier front end and an isolated phase-shifted full-bridge (PSFB) DC/DC converter. Digital control is implemented on an STM32 microcontroller using four cascaded PI control loops.

This work was accepted for oral presentation at icSmartGrid 2026 (14th International Conference on Smart Grid, Suceava, Romania).
